# 推笺 · PostNote

> 把值得留下的推文，存成一张图。

运行在 X / Twitter 页面上的油猴脚本。点一下推文旁的 PostNote 图标，直接生成并下载这张图片。

当前版本：**0.4.4**

---

## 功能

- 在每条推文的操作栏旁增加一个入口，可键盘操作（Enter / Space）。
- **点击即生成**：读取这条推文 → 准备图片与字体 → 生成 PNG → 下载。中间没有对话框、没有多选、没有列表。
- **点回复就是整条链**：如果这条推文是回复，导出的图是「主推 → 中间每一层 → 这条回复」，
  顺序与页面上的线程一致，并画上连线。
  - 父推关系取自页面**自己加载的数据**（`in_reply_to_status_id_str`），脚本只是在 `document-start` 观察页面的
    fetch / XHR，不额外发请求、不读别的信息。位置、连线、作者名、“Replying to”文案一律不参与判断。
  - 链条接不上时不会假装完整：提示会说明是「父推关系没读到」「祖先没渲染在页面上」「出现环」还是「太深」，
    并只保存已确认的那一段。
- 支持：正文、换行、链接、提及、话题、Emoji、静态图片、作者头像。
- **引用推文一起导出**：正文下方画出引用框；引用里再套一层按 X 的紧凑样式画出，更深不画（与 X 一致）。
- **视频和 GIF 显示封面**：导出封面图 + 播放按钮 +「视频 / GIF」角标，不再整条拒绝。
- **认证标与标识原样保留**：蓝标、金标（企业 / 机构账号）、灰标（政府机构）；名字后的所属组织小图标、
  企业账号的方形头像也都在。
- **页面显示翻译就导出译文**：原样照页面显示的来。
- **页脚带来源**：卡片底部写原帖地址（多条时附「· 共 N 条」）和「推笺 PostNote」，图转出去也能查回出处。
- 时间行与 X 详情页同款：时间 · 日期 · N 次查看；评论 / 转发 / 喜欢 / 书签四项数字与 X 的写法一致。
- 互动数只显示页面真实给出的值；读不到就不显示，不会用 0 顶替。
- **窄栏里入口会让位**：看图弹窗右栏的操作栏放不下时，入口挪到推文头部「⋯」左边，不再挤着数字。
- 结果用页面右下角的提示条反馈：生成中、已保存、失败原因、以及实际使用的输出倍率；错误提示点一下可关闭。
- 导出文件名：`postnote-<作者>-<推文ID>.png`（多条为 `postnote-thread-<条数>-<主推ID>.png`）。
- 一条推文最长也放不下时，按能容纳的倍率输出，并在提示里写明**实际倍率与像素尺寸**；连 1× 都放不下才拒绝。

## 不支持的

- 投票：检测到就**拒绝导出**并说明原因，不会导出一张缺内容的图。
- 视频和 GIF 只出封面：流本身不进图，封面 + 角标的形式与 X 页面上一致。
- 折叠的长文：导出前自动点开页面自己的「顯示更多」，把整段读进来（页面会因此保持展开状态，跟手动点一样）；
  万一没能展开，会停止导出并提示，不会给你半段。
- 手动多选、拼接长图：不提供。自动链条只收祖先路径，不收同层其他人的回复、广告或推荐。
- 超长内容不会拆成多张图导出。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 [最新版本的 postnote.user.js](https://github.com/kanzaki-chiya/postnote/releases/latest/download/postnote.user.js)，
   Tampermonkey 会弹出安装页，点「安装」。也可以在 [Releases](https://github.com/kanzaki-chiya/postnote/releases) 里选择其他版本。
3. 刷新任意 `x.com` / `twitter.com` 页面，在推文操作栏旁点 PostNote 图标。

第一次保存时浏览器可能询问是否允许下载多个文件，允许后即可连续保存。

与旧脚本并行时请自行停用其中一个，PostNote 不会动你的其他安装。

## 本地开发

```bash
npm install
npm run dev      # 开发版，按终端提示安装
npm test         # vitest
npm run build    # 类型检查 + 产出 dist/postnote.user.js
```

版本号只在 `package.json` 里维护，脚本头在构建时读取。

## 已知限制

- 回复链最多 50 层。
- 链条依赖页面自己加载过的数据。脚本在 `document-start` 安装时覆盖整次浏览；若会话数据在脚本生效前就已加载
  （例如刚安装脚本、页面已经开着），会提示「没有读到父推关系」并只保存这一条——刷新页面或点推文时间打开详情页即可。
